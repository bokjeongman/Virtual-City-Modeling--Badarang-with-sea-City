# 바다랑

바다의 활기와 마을의 일상이 공존하는 도시 시뮬레이션입니다.

창고형 마트를 해수욕장 근처에 둔 **해변형**과 도시 입구 근처에 둔 **입구형**을 28일 동안 비교합니다.
마트 위치에 따라 관광객과 주민의 이동, 혼잡, 소음, 인구가 어떻게 달라지는지 확인할 수 있습니다.
계절(관광객 수와 도착 요일), 마트 수·위치, 숙소 위치를 바꿔 같은 조건에서 하나씩 비교할 수도 있습니다.

- 과목: 가상공간과 메타버스
- 작성자: 202235063 송태규

## 실행 방법

폴더의 파일을 모두 같은 위치에 둔 뒤, 해당 폴더에서 실행합니다.

```bash
python app.py
```

## 의존성

- Python 3
- Tkinter (GUI)
- 그 외 Python 표준 라이브러리만 사용하므로 `pip`로 설치할 패키지는 없습니다.

## 다른 컴퓨터에서 실행

1. Python 3을 설치합니다. Windows 설치 프로그램에서는 `tcl/tk and IDLE` 항목을 선택합니다.
2. 아래 파일 구조의 Python 파일 6개를 같은 폴더에 복사합니다.
3. `python -m tkinter`로 Tkinter 창이 뜨는지 확인합니다.
4. 해당 폴더에서 `python app.py`로 프로그램을 시작합니다.

GUI 프로그램이므로 화면이 있는 환경에서 실행해야 합니다. 일부 Linux에서는 Tkinter를 따로 설치해야 합니다(예: `sudo apt install python3-tk`).

## 파일 구조

```text
.
├── app.py             # 실행 진입점과 시작 오류 처리

├── badarang_rules.py  # 계절 설정, 장보기, 관광객 동선, 혼잡 단계·소음 판정, 인구 갱신, 28일 실험·마트별 집계
├── city_data.py       # 도시 초기화, 마트 추가·삭제, 숙소 이동, 상태 검증, JSON 저장·불러오기(계절 포함), 요일 표시
├── model.py           # 이웃 칸, 전체 인구, 점유율, 도로 접근성 조회

```

## 사용법

| 조작 | 기능 |
|---|---|
| 해변형 / 입구형 | 해당 배치의 1일차 월요일 낮 상태로 새로 시작 |
| 계절 | 겨울 / 기본 / 여름 중 선택. 상단 요약에 표시되며 '다음 시간대'와 '28일 비교'부터 적용 |
| 마트 배치 모드 | 1일차 낮에만 사용. 빈 칸을 클릭하면 그 칸을 왼쪽 위로 2×2 마트 추가, 마트를 클릭하면 삭제 |
| 숙소 이동 모드 | 1일차 낮에만 사용. 숙소를 클릭해 고른 뒤(주황 테두리) 빈 칸을 클릭하면 이동. 같은 숙소를 다시 클릭하면 취소 |
| 다음 시간대 | 낮→저녁→다음 날 낮 순서로 시간 진행 |
| 실험 시작으로 | 현재 실험의 시작 상태로 복원 |
| 28일 비교 | 해변형·입구형(직접 배치했다면 '내 배치' 포함)을 각각 28일 실행해 지표, 마트별 방문객(주민 + 관광객), 주거지별 변화, 날짜별 변화를 새 창에 표시 (현재 도시는 바뀌지 않음) |
| 저장 / 불러오기 | 도시 상태, 실행 기록, 계절을 JSON 파일로 저장하거나 불러오기. 계절이 없는 예전 파일은 기본 계절로 불러옴 |
| 지도 클릭 | 칸 정보 표시. 저녁에는 도로 통행량, 주거지의 혼잡 피해 단계·소음 노출, 마트의 주민·관광객 방문객도 표시 |

마트와 숙소의 위치는 1일차 낮에만 바꿀 수 있고, 바꾸면 그 배치가 새 실험의 시작 상태가 됩니다.
두 배치 모드는 한 번에 하나만 켜집니다.

저녁 지도 표시는 다음과 같습니다.

- 빨간 네모: 혼잡한 도로 칸
- 빨간 테두리: 혼잡에 노출된 주거지
- 진한 빨간 굵은 테두리: 심한 혼잡에 노출된 주거지
- 보라색 테두리: 소음에 노출된 주거지
- 파란선 / 초록선: 관광객이 도착한 저녁의 L1 / L2 관광객 경로

낮에 숙소 이동 모드에서 고른 숙소는 주황 굵은 테두리로 표시됩니다.

## 주요 규칙

- **시간:** 하루는 낮과 저녁으로 나뉘며, 저녁에 이동과 피해를 계산하고 다음 날 낮에 인구를 갱신합니다.
- **장보기:** 도로로 마트에 갈 수 있는 주거지의 주민은 매일 저녁 BFS 최단 경로로 가장 가까운 마트에 갑니다. 이동 횟수는 집→첫 도로 1회 + 도로 위 이동 + 마트로 들어가기 1회입니다.
- **관광객:** 도착 요일 저녁에 숙소마다 정해진 인원이 입구→해수욕장→가장 가까운 마트→숙소로 이동하고, 다음 날 저녁에 숙소에서 입구로 돌아갑니다. 들른 마트에 관광객 수를 기록합니다.
- **숙소 배정:** 관광객을 L1과 L2에 같은 인원씩 배정합니다.
- **같은 길이의 경로:** 출발·도착 후보를 정해진 순서로 비교해 먼저 찾은 경로를 택합니다. 이웃 칸은 왼쪽, 오른쪽, 위, 아래 순서로 살핍니다. 이 기준은 모든 배치에 똑같이 적용합니다.
- **혼잡:** 주거지에 맞닿은 도로 칸 중 하루 통행이 가장 많은 칸을 봅니다. 통행 12회마다 피해가 1단계씩 커집니다(12회 1명, 24회 2명, 36회 3명 감소 …). 같은 사람이 다시 지나가면 다시 셉니다. 지도에는 12회 이상을 혼잡, 24회 이상을 심한 혼잡으로 표시합니다.
- **소음:** 관광객이 도착한 저녁에, 투숙객이 있는 숙소와 맨해튼 거리 2 이하인 주거지가 피해를 입습니다.
- **도로 단절:** 관광객이 숙소까지 갈 수 없으면 그 숙소의 관광객은 오지 않습니다.

| 계절 | 관광객 도착 요일 | 숙소당 관광객 | 28일 관광객 합계 |
|---|---|---:|---:|
| 겨울 | 토 | 5명 | 40명 |
| 기본 (봄·가을) | 토 | 10명 | 80명 |
| 여름 | 금, 토 | 10명 | 160명 |

| 전날 저녁 조건 | 다음 날 인구 |
|---|---|
| 도로로 마트에 갈 수 없음 | 1명 감소 |
| 소음 피해 | 1명 감소 |
| 혼잡 피해 | 맞닿은 도로 통행 12회마다 1명 감소 (12회 1명, 24회 2명, 36회 3명 …) |
| 피해 없음, 마트 이동 10회 이내 | 1명 증가 (최대 10명) |
| 피해 없음, 마트 이동 10회 초과 | 유지 |

피해가 겹치면 가장 큰 감소 하나만 적용합니다. 인구가 0명이 되면 건물은 철거 상태가 되고, 조건이 좋아져 인구가 다시 늘면 재건축됩니다.

## 추가 실험 (28일 마지막 날 인구)

한 번에 한 가지 조건만 바꾸고 나머지는 위 기준과 같게 두었습니다.

**계절**

| 계절 | 해변형 | 입구형 |
|---|---:|---:|
| 겨울 | 20명 | 5명 |
| 기본 | 16명 | 3명 |
| 여름 | 10명 | 3명 |

**숙소당 관광객 수 (기본 계절)**

| 숙소당 관광객 | 0명 | 5명 | 10명 | 15명 | 20명 |
|---|---:|---:|---:|---:|---:|
| 해변형 | 34명 | 20명 | 16명 | 13명 | 10명 |
| 입구형 | 11명 | 5명 | 3명 | 3명 | 3명 |

관광객이 늘수록 해변형 인구가 계속 줄어듭니다. 입구형은 10명부터 3명으로 같은데, 관광객 경로와 떨어져 피해가 없는 H4만 남은 상태이기 때문입니다(H4는 마트까지 이동 11회라 늘지도 않습니다).

**마트 수와 위치 (겨울 / 기본 / 여름)**

| 마트 | 마지막 날 인구 |
|---|---|
| 해변형 (10,3) 1개 | 20 / 16 / 10명 |
| 입구형 (1,3) 1개 | 5 / 3 / 3명 |
| (7,0) 1개 | 20 / 16 / 10명 |
| (4,4) 1개, 주거지 사이 | 9 / 6 / 3명 |
| (2,4) 1개, 도로 없음 | 0 / 0 / 0명 |
| (10,3) + (1,3) 2개 | 24 / 14 / 10명 |

마트가 2개일 때(기본 계절) 해변 쪽 M1은 주민 628명 + 관광객 80명, 입구 쪽 M2는 주민 275명 + 관광객 0명이 이용했습니다. 관광객은 모두 해수욕장에서 가까운 M1에 들릅니다.

**숙소 위치 (기본 / 여름, 괄호는 기본 계절 소음 노출 합계)**

| 숙소 위치 | 해변형 | 입구형 |
|---|---|---|
| 기본 위치 | 16 / 10명 (12) | 3 / 3명 (12) |
| L1만 (5,5)로 | 16 / 10명 (4) | 3 / 3명 (4) |
| 입구 옆 L1 (0,3), L2 (0,1) | 27 / 17명 (4) | 8 / 8명 (4) |

L1을 옮기면 소음은 줄지만 인구는 그대로입니다. 소음 피해를 받던 집이 같은 저녁에 혼잡 피해도 받고 있기 때문입니다.
숙소를 입구 옆에 두면 일요일 귀가 경로가 주거지 옆 도로를 지나지 않아 일요일 피해가 사라집니다(해변형 일요일 혼잡 14칸 → 1칸).
숙소 위치는 소음보다 관광객 동선을 통해 인구에 더 크게 영향을 줍니다.

## 개선 이력

만들면서 찾은 한계 두 가지를 고쳤습니다.

| 한계 | 개선 | 효과 |
|---|---|---|
| 혼잡 피해가 24회(−2명)에서 멈춰, 숙소당 관광객 10·15·20명 결과가 모두 같았음 (해변형 18·18·18명) | 맞닿은 도로 통행 12회마다 1명씩 감소 (36회 3명, 48회 4명 …) | 해변형 16·13·10명으로 관광객 수 효과가 보임 |
| 관광객이 어느 마트에 들렀는지 세지 않았음 | 관광객이 들른 마트에 인원 기록, 28일 비교 창에 마트별 주민 + 관광객 표시 | 마트 2개일 때 관광객 80명이 모두 해변 쪽 M1 이용 |

## 참고 사항

- 시뮬레이션에 난수를 쓰지 않아 같은 조건에서는 항상 같은 결과가 나옵니다.
- 28일차는 일요일입니다. 숙소 기본 위치에서는 주말 피해가 쌓인 뒤라 마지막 날 인구가 주간 최저 시점의 값입니다.
- 피해는 겹쳐도 가장 큰 감소 하나만 적용합니다.
- 도로가 닿지 않는 칸에 숙소를 두면 관광객이 오지 않으므로, 이런 결과는 숙소 위치 효과가 아니라 관광객 감소 효과입니다.
- 혼잡 단계가 없던 예전 저장 파일을 불러오면 그 저녁은 예전 규칙(혼잡 1명, 심한 혼잡 2명)으로 갱신합니다.
- 결과는 이 모형의 규칙과 가정 안에서 나온 것이며, 실제 도시 자료로 검증한 값은 아닙니다.

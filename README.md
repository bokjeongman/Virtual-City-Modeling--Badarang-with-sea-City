# 바다랑

바다의 활기와 마을의 일상이 공존하는 도시 시뮬레이션입니다.

창고형 마트를 해수욕장 근처에 둔 **해변형**과 도시 입구 근처에 둔 **입구형**을 28일 동안 비교합니다.
마트 위치에 따라 관광객과 주민의 이동, 혼잡, 소음, 인구가 어떻게 달라지는지 확인할 수 있습니다.

- 과목: 가상공간과 메타버스
- 작성자: 202235063 송태규

## 실행 방법

폴더의 파일을 모두 같은 위치에 둔 뒤, 해당 폴더에서 실행합니다.

```bash
python app.py
```


## 의존성

- Python 3
- Tkinter (GUI)
- 그 외 Python 표준 라이브러리만 사용하므로 `pip`로 설치할 패키지는 없습니다.

## 다른 컴퓨터에서 실행

1. Python 3을 설치합니다. Windows 설치 프로그램에서는 `tcl/tk and IDLE` 항목을 선택합니다.
2. 아래 파일 구조의 Python 파일 6개를 같은 폴더에 복사합니다.
3. `python -m tkinter`로 Tkinter 창이 뜨는지 확인합니다.
4. 해당 폴더에서 `python app.py --smoke`를 실행한 뒤, `python app.py`로 프로그램을 시작합니다.

GUI 프로그램이므로 화면이 있는 환경에서 실행해야 합니다. 일부 Linux에서는 Tkinter를 따로 설치해야 합니다(예: `sudo apt install python3-tk`).

## 파일 구조

```text
.
├── app.py             # 실행 진입점, 명령행 옵션과 시작 오류 처리
├── gui.py             # Tkinter 화면, 지도 표시, 실행 기록, 28일 비교 창
├── badarang_rules.py  # 장보기, 관광객 동선, 혼잡·소음 판정, 인구 갱신, 28일 실험
├── city_data.py       # 도시 초기화, 상태 검증, JSON 저장·불러오기, 요일 표시
├── model.py           # 이웃 칸, 전체 인구, 점유율, 도로 접근성 조회
├── traffic.py         # 도로 그래프와 BFS 최단 경로
└── README.md
```

## 사용법

| 조작 | 기능 |
|---|---|
| 해변형 / 입구형 | 해당 배치의 1일차 월요일 낮 상태로 새로 시작 |
| 다음 시간대 | 낮→저녁→다음 날 낮 순서로 시간 진행 |
| 실험 시작으로 | 현재 실험의 시작 상태로 복원 |
| 28일 비교 | 두 배치를 각각 28일 실행해 지표, 주거지별 변화, 날짜별 변화를 새 창에 표시 (현재 도시는 바뀌지 않음) |
| 저장 / 불러오기 | 도시 상태와 실행 기록을 JSON 파일로 저장하거나 불러오기 |
| 지도 클릭 | 칸 정보 표시. 저녁에는 도로 통행량과 주거지의 혼잡·소음 노출도 표시 |

저녁 지도 표시는 다음과 같습니다.

- 빨간 네모: 혼잡한 도로 칸
- 빨간 테두리: 혼잡에 노출된 주거지
- 보라색 테두리: 소음에 노출된 주거지
- 파란선 / 초록선: 토요일 저녁 L1 / L2 관광객의 경로

## 주요 규칙

- **시간:** 하루는 낮과 저녁으로 나뉘며, 저녁에 이동과 피해를 계산하고 다음 날 낮에 인구를 갱신합니다.
- **장보기:** 도로로 마트에 갈 수 있는 주거지의 주민은 매일 저녁 BFS 최단 경로로 마트에 갑니다.
- **관광객:** 토요일에 20명이 입구→해수욕장→마트→숙소로 이동하고, 일요일 저녁에 숙소에서 입구로 돌아갑니다.
- **숙소 배정:** 토요일 관광객을 L1과 L2에 10명씩 배정합니다.
- **같은 길이의 경로:** 출발·도착 후보를 정해진 순서로 비교해 먼저 찾은 경로를 택합니다. 이웃 칸은 왼쪽, 오른쪽, 위, 아래 순서로 살핍니다.
- **혼잡:** 한 도로 칸의 하루 통행 횟수가 12회 이상이면 혼잡이며, 맞닿은 주거지가 피해를 입습니다. 같은 사람이 다시 지나가면 다시 셉니다.
- **소음:** 토요일 저녁에 숙소와 맨해튼 거리 2 이하인 주거지가 피해를 입습니다.
- **도로 단절:** 관광객이 숙소까지 갈 수 없으면 그 숙소의 관광객은 오지 않습니다.

| 전날 저녁 조건 | 다음 날 인구 |
|---|---|
| 도로로 마트에 갈 수 없음, 또는 혼잡·소음 피해 | 1명 감소 (겹쳐도 1명) |
| 피해 없음, 마트 이동 10회 이내 | 1명 증가 (최대 10명) |
| 피해 없음, 마트 이동 10회 초과 | 유지 |

인구가 0명이 되면 건물은 철거 상태가 되고, 조건이 좋아져 인구가 다시 늘면 재건축됩니다.
